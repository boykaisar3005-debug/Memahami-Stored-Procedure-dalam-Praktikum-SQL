Pendahuluan

Pada praktikum minggu ini saya mempelajari tentang Stored Procedure pada SQL Server menggunakan SQL Server Management Studio (SSMS). Stored Procedure merupakan sekumpulan query SQL yang disimpan di dalam database dan dapat dijalankan kembali menggunakan perintah tertentu.

Praktikum ini membantu saya memahami bagaimana stored procedure dapat digunakan untuk membuat query lebih rapi, efisien, dan mudah digunakan kembali.

Level 1 - Procedure Tanpa Parameter

Pada level pertama saya mempelajari cara membuat stored procedure tanpa parameter. Procedure dibuat menggunakan CREATE PROCEDURE dan dijalankan menggunakan EXEC. 

CREATE PROCEDURE tampilMahasiswa
AS
BEGIN
   SELECT * FROM mahasiswa
END

Pada awal praktikum terjadi beberapa error karena menggunakan sintaks MySQL seperti DELIMITER, AUTO_INCREMENT, dan CALL yang tidak didukung di SQL Server.

Solusi yang dilakukan yaitu mengganti:

  • AUTO_INCREMENT menjadi IDENTITY(1,1)
  • CALL menjadi EXEC
  • DELIMITER diganti menggunakan GO

Level 2 - Procedure dengan 1 Parameter IN

Pada level ini saya membuat stored procedure dengan satu parameter input. Procedure digunakan untuk menampilkan data mahasiswa berdasarkan ID program studi tertentu. 

CREATE PROCEDURE getMahasiswaByProdi
  @p_idprodi INT
AS
BEGIN
   SELECT npm, nama, idprodi
   FROM mahasiswa
   WHERE idprodi = @p_idprodi
END

Procedure dijalankan menggunakan: 

EXEC getMahasiswaByProdi 1

Hasil output menampilkan data mahasiswa sesuai program studi yang dipilih.

Level 3 - Procedure dengan 2 Parameter IN

Pada level ini saya mempelajari penggunaan dua parameter input pada stored procedure. Query digunakan untuk mencari data mahasiswa berdasarkan program studi dan semester. 

CREATE PROCEDURE cariMahasiswa
  @p_prodi INT,
  @p_semester INT
AS
BEGIN
   SELECT *
   FROM mahasiswa
   WHERE idprodi = @p_prodi
   AND semester = @p_semester
END
    
EXEC cariMahasiswa 1, 4

Dengan penggunaan lebih dari satu parameter, proses pencarian data menjadi lebih spesifik dan efisien.

Level 4 - Procedure dengan JOIN

Pada level ini saya mempelajari penggunaan JOIN antar tabel di dalam stored procedure. Query digunakan untuk menampilkan data KRS mahasiswa. 

CREATE PROCEDURE tampilDataKRS
  @p_npm VARCHAR(20)
AS
BEGIN
   SELECT m.npm, m.nama, mk.namamatkul, mk.sks
   FROM mahasiswa m
   JOIN krs k ON m.npm = k.npm
   JOIN matakuliah mk ON k.kodemk = mk.kodemk
   WHERE m.npm = @p_npm
END

Hasil output menampilkan data mahasiswa, mata kuliah yang diambil, dan jumlah SKS. Penggunaan JOIN membantu menghubungkan beberapa tabel sehingga informasi menjadi lebih lengkap.

Level 5 - Procedure dengan Fungsi Agregat

Pada level ini saya mempelajari penggunaan fungsi agregat seperti COUNT, SUM, AVG, MAX, dan MIN pada stored procedure.

Fungsi agregat digunakan untuk melakukan perhitungan data secara otomatis di dalam database. 

SELECT COUNT(*) AS jumlah_mahasiswa
FROM mahasiswa

Praktikum ini membantu memahami bagaimana database dapat digunakan untuk melakukan pengolahan data dengan lebih cepat dan efisien.

Kesimpulan

Pada praktikum ini saya mempelajari konsep Stored Procedure pada SQL Server mulai dari procedure tanpa parameter, parameter input, penggunaan JOIN antar tabel, hingga fungsi agregat.

Dengan menggunakan stored procedure, query menjadi lebih terstruktur, mudah digunakan kembali, dan mempermudah pengelolaan database yang kompleks.
