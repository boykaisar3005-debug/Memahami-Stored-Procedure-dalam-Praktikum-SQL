Multi Parameter pada Stored Procedure

Pada materi ini saya mempelajari penggunaan lebih dari satu parameter input pada stored procedure. Multi-parameter digunakan untuk melakukan filter data yang lebih spesifik. 

CREATE PROCEDURE filterMhs
  @p_prodi INT,
  @p_thn INT
AS
BEGIN
   SELECT *
   FROM mahasiswa
   WHERE idprodi = @p_prodi
   AND thn_masuk = @p_thn
END

Query tersebut digunakan untuk menampilkan data mahasiswa berdasarkan program studi dan tahun masuk tertentu.

IF / ELSE pada Stored Procedure

Pada praktikum ini saya juga mempelajari penggunaan kontrol alur IF dan ELSE di dalam stored procedure. 

IF @mode = 1
BEGIN
   SELECT * FROM mahasiswa
END
ELSE
BEGIN
   SELECT * FROM dosen
END

Dengan IF dan ELSE, stored procedure dapat menjalankan query berbeda sesuai kondisi tertentu.

Parameter OUT

Parameter OUT digunakan untuk menghasilkan nilai keluaran dari stored procedure. Nilai tersebut dapat disimpan ke variabel tertentu. 

CREATE PROCEDURE countMhs
  @p_prodi INT,
  @p_count INT OUTPUT
AS
BEGIN
   SELECT @p_count = COUNT(*)
   FROM mahasiswa
   WHERE idprodi = @p_prodi
END

Praktikum ini membantu memahami bagaimana stored procedure dapat mengembalikan data hasil perhitungan menggunakan parameter output.

DML pada Stored Procedure

Pada materi ini saya mempelajari penggunaan operasi DML seperti INSERT, UPDATE, dan DELETE di dalam stored procedure.

INSERT

INSERT INTO mahasiswa(npm, nama)
VALUES('24781076', 'Chaesar')

UPDATE

UPDATE mahasiswa
SET nama = 'Chaesar Abdullah'
WHERE npm = '24781076'

DELETE

DELETE FROM mahasiswa
WHERE npm = '24781076'

Dengan DML pada stored procedure, proses manipulasi data menjadi lebih terstruktur dan mudah digunakan kembali.

JOIN dan Fungsi Agregat

Praktikum juga membahas penggunaan JOIN antar tabel serta fungsi agregat seperti COUNT(), AVG(), dan SUM(). 

SELECT p.nmprodi, COUNT(m.npm) AS jumlah_mahasiswa
FROM prodi p
JOIN mahasiswa m
ON p.idprodi = m.idprodi
GROUP BY p.nmprodi

Query tersebut digunakan untuk menghitung jumlah mahasiswa pada setiap program studi.
