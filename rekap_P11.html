Query yang digunakan pada praktik ini adalah pembuatan stored procedure bernama cariMahasiswa dengan dua parameter input yaitu @p_prodi dan @p_semester bertipe INT. Procedure dibuat menggunakan CREATE PROCEDURE dan dijalankan menggunakan EXEC cariMahasiswa 1, 4.

Tujuan query ini adalah untuk mencari dan menampilkan data mahasiswa berdasarkan program studi dan semester tertentu. Query mengambil seluruh data dari tabel mahasiswa dengan kondisi WHERE idprodi = @p_prodi dan semester = @p_semester sehingga hasil yang ditampilkan sesuai dengan parameter yang diberikan.

Hasil output yang diperoleh menampilkan data mahasiswa yang memiliki idprodi bernilai 1 dan semester bernilai 4. Data berhasil difilter sesuai kondisi yang ditentukan pada stored procedure.

Pada awal praktik, saya memahami bahwa penggunaan parameter lebih dari satu memungkinkan proses pencarian data menjadi lebih spesifik. Query berhasil dijalankan di SQL Server Management Studio (SSMS) menggunakan sintaks EXEC untuk memanggil stored procedure. Praktik ini membantu memahami penggunaan multiple parameter pada stored procedure untuk proses filter data yang lebih detail dan efisien.

Query mengambil data npm dan nama mahasiswa dari tabel mahasiswa, kemudian menggabungkannya dengan tabel krs dan matakuliah menggunakan JOIN untuk menampilkan nama mata kuliah serta jumlah SKS yang diambil mahasiswa.

Pada proses praktik, query berhasil dijalankan setelah menggunakan sintaks SQL Server yang sesuai di SSMS. Penggunaan JOIN membantu menghubungkan beberapa tabel sehingga informasi yang ditampilkan menjadi lebih lengkap dan terstruktur. Praktik ini membantu memahami penggunaan stored procedure dengan parameter input dan relasi antar tabel dalam database AKADEMIK.
